# simulation-of-Bayesian-Network-systems-for-fire-alarm-surveillance
This study presents the design and simulation of a five-node Bayesian Network for fire detection using 62,630 records from the Kaggle Smoke Detection Dataset. 
The model integrates multiple environmental sensor variables and incorporates a validated Smoke, Humidity, CO and Temperature relationship to enhance probabilistic inference. 
Its performance is evaluated under three conditions: the original dataset, a rebalanced dataset, and simulated sensor fault scenarios. 
The results demonstrate recall above 90% across all evaluation tiers, accurate probability calibration, and an average inference time of 0.95 milliseconds per record.
The study contributes a structured approach to assessing the accuracy, reliability, and robustness of Bayesian Network-based fire detection systems under varying operating conditions.
